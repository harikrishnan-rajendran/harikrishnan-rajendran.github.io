# Personal academic website

A responsive, minimalist research website made with plain HTML, CSS and JavaScript. No build tools or paid hosting are needed.

## Personalise
Edit `index.html` and replace all placeholder text, names, institution, email, publication details and `#` links. Replace the SVG files in `assets/` with your own research images if desired.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace this with your GitHub username).
2. Upload the contents of this folder. Ensure `index.html` is at the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. After publishing, visit `https://YOUR-GITHUB-USERNAME.github.io`.

The first deployment can take a few minutes. Later edits go live after you commit them.

Official instructions: https://docs.github.com/en/pages/quickstart
